Launch Radar

Which pre-token protocol is worth farming next — and what to do about it. Every protocol below records no token. Each is ranked by an implied value the model derives from the snapshot's own figures, never from a hand-kept list of names.

The value model

implied value = TVL × category multiple × growth × maturity × launch odds

Category multiple

The median mcap / TVL of the live-token protocols in the same category — the market's own pricing, read from this snapshot. Categories with fewer than 3 live comps use the global median.

Growth

The protocol's 7-day TVL change, clamped to −60%…+120%, at half weight. A protocol shrinking fast is worth less; one growing fast is worth more.

Maturity

0.6 + age up to 3 years × 0.4. A protocol that has run for years has a record; a brand-new one has none.

Launch odds

Among protocols of the same age band, the share that already record a token — the peers' own age curve, read from this snapshot and damped to 0.5 + 0.5 × rate.

Method and limits

The snapshot is frozen: 758 protocols at or above $5M of TVL, fetched from DefiLlama on 14 November 2026. The board ranks 198 of them — every protocol that records no token and is not an exchange, a versioned pool, or a wrapped, staked or bridged product — including all 40 on the watchlist. A protocol is called pre-token only because its record carries no token; it may still have one its record does not carry. The implied value is this entry's own claim, never make.fun's, and it is not a prediction that a token will be issued or when. Farm plans are starting points, not financial advice: check the protocol's own page before sending funds anywhere.
